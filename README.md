# Portfolio — Alexis Michaux

Mon portfolio d'étudiant à Epitech Nancy : qui je suis, mes projets, mon parcours et comment me contacter.

# Structure


- index.html      Accueil : photo, phrase d'accroche, CV
- projets.html    Projets : contexte, objectif, technologies, liens
- parcours.html   Ce que j'apprends, formation, expériences
- a-propos.html   Présentation, centres d'intérêt, langues, certifications
- contact.html    Coordonnées et formulaire de contact
- style.css       Le style de toutes les pages
- images/         Photos
- cv.pdf          Mon CV à télécharger


Chaque page a le même menu. Le lien de la page en cours porte la classe `actif`.

# Technologies

- HTML et CSS, sans framework ni JavaScript : un site simple que je peux expliquer ligne par ligne.
- Mise en page avec Flexbox, responsive grâce à `flex-wrap` et une media query.
